// 03 CORE CAPABILITIES

Engineered for Technical Builders

No accounts, no subscriptions, no cloud latency. Native Swift tools for engineers, architects, and product leads who think out loud.

Decoupled Two-Stage Intelligence

Speech recognition is strictly decoupled from LLM summarization. Stage 1 executes WhisperKit CoreML for verbatim acoustic decoding, producing an immutable transcript audit trail. Stage 2 executes the native Apple Foundation Model by default (with opt-in Qwen3 via MLX Swift) to generate structured technical requirements, condition trees, and actionable task checklists.

WhisperKit CoreML Apple Neural Engine Apple Foundation Model MLX Swift Metal GPU Private Ollama LAN

Apple Watch Standalone

One-touch complication on your watch face (Circular, Corner, Rectangular, Inline) captures ideas instantly without waiting for iPhone. Preserves battery with offline AAC encoding, automatically syncing in the background when in range.

WidgetKit Complications WatchConnectivity Zero Battery Drain

macOS Menubar & Global Hotkey

Press ⌥ Space anywhere in macOS to trigger a floating recording HUD. Dictate stream-of-consciousness thoughts; Voxbrief processes the spec locally and uses accessibility synthetic events to paste structured Markdown directly into VS Code, Xcode, or Obsidian.

Global Hotkey ⌥ Space Menubar Daemon CGEvent Direct Paste

Personal Technical Dictionary

A built-in regex word-boundary filter guarantees custom domain jargon, acronyms, and proprietary library names (e.g. CoreML, Kubernetes, gRPC, PostgreSQL) are strictly protected from speech recognition drift and LLM hallucination.

// 06 DEVELOPER TOOLCHAIN

Inspect & Build from Source

Voxbrief uses XcodeGen and native Swift Package Manager. Clone, generate project files, and run the test suite in terminal.

# 1. Clone repository
git clone https://github.com/tianhaoz95/voxbrief.git
cd voice-note

# 2. Generate Xcode project via XcodeGen
xcodegen generate

# 3. Resolve WhisperKit & MLX dependencies
xcodebuild -resolvePackageDependencies -project Voxbrief.xcodeproj -scheme Voxbrief
